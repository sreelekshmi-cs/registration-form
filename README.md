JavaScript Registration Form

Overview

A responsive and user-friendly registration form developed to practice frontend web development and JavaScript form validation.

Features

- Name, email, and password input fields
- Form validation
- Error message handling
- Password visibility toggle
- Clean and intuitive user interface

Technologies Used

- HTML5
- CSS3
- JavaScript

Project Structure

- "index.html" – Contains the form structure and JavaScript code
- CSS styles – Defines the form layout and appearance

Purpose

This project demonstrates basic frontend development skills and client-side form validation using JavaScript.
